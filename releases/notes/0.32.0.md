## 亮点
- 适配桌面客户端更名为 ChatGPT，统一会话标签、来源徽标、消息预览和引导文案；继续兼容旧版 Codex App，保留 Codex CLI 的名称与终端跳转
- 完成通知按会话回合独立排队，在停靠和悬浮 Island 之间共享；其他任务仍在运行或面板已打开时，也不会直接丢弃通知（#320）
- 加强 SSH 远程连接恢复：断线后自动重试连接，重放有界队列中尚未确认的事件，并明确显示远程会话的断开状态（#321）

## 修复
- 将 Codex 自动审批审查交回 Codex 处理，避免误弹人工审批卡片；真正需要用户确认或回答的问题仍可交互，原有审批策略与沙箱权限保持不变（#319）
- 修复后台读取 Codex 会话时，待处理审批或问题被覆盖的问题；在读取期间到达的新请求和处理结果会保留正确卡片与状态（#319）
- 以稳定的回合标识去重完成弹窗和声音，避免延迟日志或重复快照触发二次提醒；已有明确完成状态的回合不再等待最终回复文本写入日志（#320）
- 修复日志补全覆盖当前自动审批设置的问题，保留用户刚修改的开关以及会话结束时的重置（#320）
- 保留 Codex 回合中断状态，避免旧快照或空闲刷新把已中断任务误报为成功；同一回合的多次上下文压缩可分别提醒，每次压缩只提醒一次
- 断开的远程会话不再维持虚假的工作或可操作审批状态，也不会继续触发声音、保持唤醒或自动展开；远程 PID 不再被当作本机进程检查（#321）
- 保留尚未回答的本地终端问题，以及仍连接的等待输入和近期完成会话的悬停预览（#321）
- 修复设置窗口主题背景遮挡内容和原生窗口按钮、导致窗口空白或无法点击的问题，覆盖首次打开、切换主题和调整窗口大小（#323）

## 改进
- 优先识别经过应用身份校验的 `ChatGPT.app`，并保留 `Codex.app` 回退与旧会话缓存兼容
- 远程桥接事件在本机接收处理后才确认送达；连接时校验桥接程序内容，替换不匹配的旧版本（#321）
- 补充自动审查、审批与问题并发更新、完成通知、中断与压缩、远程重放及设置窗口的回归覆盖

- 远程协议改进需要远程主机使用本版本匹配的桥接程序；事件重放队列有容量上限，溢出时会丢弃最旧事件
- 手动安装优先使用 DMG；同时提供 ZIP、Sparkle 自动更新与 Linux x86_64 / aarch64 远程桥接包

## Highlights
- Adapts desktop session labels, source badges, message previews, and onboarding to the ChatGPT rename, while retaining compatibility with the former Codex App and preserving Codex CLI names and terminal navigation
- Queues completion notifications independently by turn across docked and floating Island, so another running task or an already-open panel no longer causes a notification to be discarded (#320)
- Improves SSH recovery with automatic reconnect retries, replay of unacknowledged events from a bounded queue, and explicit disconnected states for remote sessions (#321)

## Fixes
- Leaves Codex automatic approval reviews to Codex instead of showing them as human approval cards; genuine approval and question requests remain interactive without changing approval policy or sandbox permissions (#319)
- Preserves pending Codex approvals and questions during background thread reads, including newer requests and resolutions arriving while a read is in progress (#319)
- Uses stable turn identities to prevent duplicate completion popups and sounds after delayed transcript updates or repeated snapshots; turns with confirmed completion no longer need to wait for final reply text to reach the transcript (#320)
- Keeps transcript enrichment from overwriting current automatic approval preferences, including concurrent user toggles and resets when a session ends (#320)
- Preserves interrupted Codex turns through stale snapshots and idle refreshes so they are not announced as successful; multiple context compactions within one turn can each notify once
- Prevents disconnected remote sessions from claiming active work or actionable approvals, producing sounds, keeping the Mac awake, or automatically expanding Island; remote PIDs are no longer checked as local processes (#321)
- Preserves unanswered local terminal questions and hover previews for connected sessions waiting for input or recently completed (#321)
- Fixes settings theme backdrops covering content and native window controls, causing blank windows or blocked clicks during initial presentation, theme changes, and resizing (#323)

## Improvements
- Prefers identity-validated `ChatGPT.app` discovery, with a `Codex.app` fallback and compatibility for existing session caches
- Acknowledges remote bridge events after the Mac ingests them, and checks bridge binary contents on connection so mismatched older versions are replaced (#321)
- Expands regression coverage for automatic review, concurrent approval and question updates, completion notifications, interruption and compaction, remote replay, and settings windows

## Notes
- App version `0.32.0`, build `83`; covers `v0.31.0...v0.32.0`
- Remote protocol improvements require the matching bridge from this release on the remote host; the replay queue is bounded and drops its oldest events on overflow
- Use the DMG for manual installation; ZIP, Sparkle updates, and Linux x86_64 / aarch64 remote bridge packages are also provided
- [Full changelog](https://github.com/erha19/ping-island/compare/v0.31.0...v0.32.0)
