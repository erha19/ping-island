## Fixes
- Fixes completion detection when Codex sessions over SSH receive a Stop hook, including completed turns without a final reply body (#322)
- Preserves formatting in hook-provided remote Codex prompts and final replies, avoiding duplicate completion alerts, duplicate replies, and stale content from earlier turns across docked and floating modes (#322)
- Fixes Qoder / Qoder CN desktop app identification alongside IDE and CLI integrations, improving session labels, cached identity repair, and activation of the corresponding app while preserving terminal navigation for real CLI sessions
- Fixes Qoder desktop question and approval handling: when every question has available options, Island submits each question's first option and retains a follow-up notice; free-text questions and ordinary approvals remain actionable
- Fixes missed attention prompts for consecutive approval requests in the same session while respecting the user's smart-suppression settings

## Improvements
- Updates the English and Chinese READMEs with community, contribution, and sponsorship links
- Expands regression coverage for remote Codex completion, Qoder product identity, real socket question and approval round trips, and consecutive approval alerts
