## 新功能
- 新增 Oh My Pi（OMP）客户端支持，可在 Island 查看会话状态并回答 `ask` 工具的问题
- 新增 Kimi 桌面版独立集成，自动恢复桌面应用重启后被重写的 hooks 配置

## 改进
- 点击 Claude 桌面版托管的会话时，直接跳转到对应标签页
- 改善同一工作目录下多个 Claude 会话的共存与活跃状态判断
- 为运行中工具和进程存活证据增加有效期，减少异常退出后会话长期卡在运行中的情况

## 修复
- 修复 IDE 宿主信息覆盖真实客户端身份，导致 Claude 会话被误识别为 Qoder / Qoder CN 的问题
- 修复点击外接显示器上关闭的 Island 时，同时触发背后菜单栏图标的问题，并覆盖低功耗模式
- 修复远程 Codex 快照覆盖实时会话状态的问题
- 修复历史转录重放或异步解析将已结束会话重新变为运行中、重新创建已归档会话的问题
- 修复缺少转录文件时误读其他客户端或相邻会话历史的问题
- 修复仅包含工具结果的转录更新被遗漏、过期执行证据阻止会话进入空闲状态的问题
- 修复 OMP 回退到原生提问界面时重复发送阻塞问题，以及 Kimi hooks 修复失败后无法重试的问题

## 说明
- 版本号为 `0.30.0`，本次重新构建将 Sparkle build 号提升到 `79`
- 发布产物通过 GitHub Actions 完成 Developer ID 签名与 Apple 公证

## New
- Adds Oh My Pi (OMP) integration for session status and answering `ask` questions in Island
- Adds a separate Kimi desktop integration that restores managed hooks after the desktop app rewrites its configuration

## Improvements
- Opens the corresponding tab when selecting a session hosted by the Claude desktop app
- Improves coexistence and activity tracking for multiple Claude sessions in the same working directory
- Bounds running-tool and process-liveness evidence so crashed agents do not leave sessions working indefinitely

## Fixes
- Prevents IDE host metadata from overriding client identity and misidentifying Claude sessions as Qoder or Qoder CN
- Prevents clicks on the closed Island on external displays from also activating menu bar items underneath, including in low-power modes
- Prevents remote Codex snapshots from overriding live session phases
- Prevents transcript replay and asynchronous parsing from reviving ended sessions or recreating archived sessions
- Prevents missing transcripts from adopting unrelated client or neighboring session history
- Delivers tool-result-only transcript updates and lets stale execution evidence expire when idle hooks arrive
- Avoids duplicate blocking OMP questions during native fallback and retries failed Kimi hook repairs

## Notes
- The app version remains `0.30.0`, and this rebuild raises the Sparkle build number to `79`
- Release artifacts are Developer ID signed and Apple-notarized through GitHub Actions
